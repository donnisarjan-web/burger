# Бургерная — запуск
1. Установите Node.js (18+).
2. В папке проекта: `npm install` затем `npm start`
3. Откройте http://localhost:3000
Продавец: регистрация с кодом продавца (по умолчанию в server.js, можно задать через переменную SELLER_CODE).
Данные хранятся в data.json, загруженные фото — в public/uploads.
